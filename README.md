# 🥗💪 Diet & Workout Recommendation System

A smart web application that provides **personalized diet and workout plans** based on your body metrics and fitness goals using Machine Learning!

## ✨ Features
- 🏋️ Personalized Workout Plans based on fitness level
- 🥗 Custom Diet Recommendations based on BMI & goals
- 📊 Progress Tracking Dashboard
- 🔐 Secure User Authentication & Profile Management
- 👑 Admin Panel for User Management

## 🛠️ Tech Stack
- **Backend:** Python & Flask
- **Machine Learning:** Scikit-learn
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript

## ⚙️ How to Run
1. Clone the repository
   git clone https://github.com/anuragjaiswar950-byte/Diet-Workout-Recommendation-ML.git
2. Install dependencies
   pip install -r requirements.txt
3. Run the app
   python app.py
4. Open browser and go to
   http://127.0.0.1:5000
